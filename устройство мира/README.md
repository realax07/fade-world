# Устройство мира

Государство, общество, история, хозяйство, вера, повседневность и границы сверхъестественного.

Исходный ориентир — XVIII век и государство, напоминающее Российскую империю. Принятые черты [Империи](../фракции/Империя/README.md) описаны в её основном разделе. Название государства — Вележская империя; общий географический каркас принят. Столица — [Велиград](../География/Города/Велиград/README.md). Подробное устройство институтов, хронология, точная карта и названия остальных мест остаются открытыми.
