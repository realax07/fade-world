# Преступные объединения

Тип: контекст группы самостоятельных сил.
Статус: общий каркас утверждён; конкретные сети пока не описаны.

В мире действуют несколько соперничающих преступных объединений, связанных с определёнными городами, промыслами и торговыми путями. Общего центра для них не установлено.

Отношения строятся через конкретных участников и посредников. Сеть может обслуживать несколько клиентов, которые не знают друг о друге; соглашение с одним человеком не означает союз со всеми, к кому он принадлежит.

Связи с отдельными [лечебными кругами](../Лечебные%20дома/README.md) могут включать тайные поставки и услуги в обмен на деньги, лечение и доступ к препаратам. Похищение людей для опытов, подделка документов и укрывательство раненых — согласованные варианты для будущей разработки, но конкретные исполнители и сделки пока не установлены.

Не все сети имеют отношение к медицине, культам и исследованиям. Их интересы и возможности предстоит определять по отдельности.

Открыты: названия, состав, территории, промыслы, внутренний порядок и конкретные связи с [домами](../Знатные%20дома/README.md), лечебницами и представителями [Империи](../Империя/README.md).
