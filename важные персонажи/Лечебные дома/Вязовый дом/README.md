# Персонажи Вязового дома

Участники [Вязового дома](../../../фракции/Лечебные%20дома/Вязовый%20дом/README.md).

- [Леонтий Саввич Руднев](./Леонтий%20Саввич%20Руднев.md) — главный врач; портрет и промпт находятся в этой папке.

[Вера Михайловна Вельская](../../остальные/Вера%20Михайловна%20Вельская.md) содержится в доме, но её карточка по указанию автора размещена в разделе «остальные». Пребывание в лечебнице не означает принадлежности к её персоналу или объединению.
