# Важные персонажи

Люди и другие действующие лица, влияющие на мир и его истории. Карточки распределяются по папкам фракций; вложенные папки уточняют положение персонажа внутри фракции. Для участников фракций принадлежность определяется расположением карточки. Раздел «остальные» — навигационная категория по указанию автора; она не отменяет родства и иных связей.

Для персонажа полезно определить положение, желания, ограничения, связи и то, каким его видят окружающие. Тайны и версии отделяются от установленных фактов.

Сущности персонажей описываются через характер, мотивы, возможности, ограничения и связи, без обязательной сюжетной роли. Командующих корпусами предстоит разработать позднее.
