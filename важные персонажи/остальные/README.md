# Остальные персонажи

Раздел для персонажей, которым автор не назначил размещение внутри папки фракции. Это навигационная категория, а не самостоятельная фракция или утверждение об отсутствии связей.

- [Вера Михайловна Вельская](./Вера%20Михайловна%20Вельская.md) — сестра Северина, содержащаяся в Вязовом доме. Портрет и промпт находятся рядом.
