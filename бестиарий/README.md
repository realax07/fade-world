# Бестиарий

Существа, возможные проявления сверхъестественного и представления о них. Отдельных описаний сущностей в разделе пока нет.

В описании полезно различать наблюдаемые следы, рассказы очевидцев, местные поверья и установленную автором правду. Не у каждого слуха должно быть реальное чудовище за спиной.

Описание существа должно различать его авторские свойства, поведение и ограничения, доступные наблюдению признаки и представления жителей. Сюжет охоты и игровые характеристики относятся к отдельному применению.
