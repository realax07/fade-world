# Фэнтезийный мир

Рабочая база мира и опорный слой для его последовательной разработки. Название мира пока не определено.

## Основа замысла

Славянское фэнтези в государстве — аллюзии на Российскую империю. Ориентир по эпохе: XVIII век. Это самостоятельный вымышленный мир, а не альтернативная история с обязательным следованием реальным событиям.

Фэнтезийное должно быть тонким, скользящим и едва заметным. Повседневная жизнь убедительна сама по себе; странное проступает через детали, слухи, обычаи и несовпадения в свидетельствах. Масштаб и выразительность сдержанные.

Источники настроения: Bloodborne, «Ведьмак», Warhammer 40 000. Их влияние подчинено славянской основе, выбранной эпохе и требованию сдержанности. Прямое заимствование узнаваемых сущностей, терминов и сюжетов не предполагается.

## Работа с материалами

Сейчас закреплена только основа замысла выше. Конкретная география, история, религии, магия, фракции и персонажи ещё не определены.

Новые идеи сначала считаются черновиками. Одобрение автора переводит их в канон. Внутри описаний следует различать установленный факт мира, версию персонажа и местное поверье: противоречивые свидетельства могут сосуществовать намеренно.

Правила для работающих с папкой агентов находятся в [AGENTS.md](./AGENTS.md).
