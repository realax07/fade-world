# Природа

Ландшафты, климат, растения, животные, времена года и их влияние на жизнь людей. Отдельных описаний сущностей в разделе пока нет.

Природа создаёт материальную основу мира: расстояния, дороги, урожай, промыслы и сезонные трудности. Странные явления вписываются в неё сдержанно; их объяснение может оставаться открытым.

Описания среды фиксируют устойчивые условия, сезонные изменения, ресурсы и ограничения для жизни. Конкретные маршруты приключений и правила выживания отдельной игры не задают свойства всей природы мира.

Формат и типы сведений: [Контекст проекта](../КОНТЕКСТ%20ПРОЕКТА.md).

Расположение природных зон и населённых мест описывается в разделе [«География»](../География/README.md); здесь развиваются свойства среды без дублирования карточек мест.
