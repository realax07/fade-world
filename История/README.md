# История

Раздел для старых хронологий и рассказов о прошлом мира. Материалов пока нет.

Здесь могут храниться авторские хронологии установленных событий, внутримировые летописи и предания, художественные рассказы. Для каждого документа указываем тип и статус: утверждённая история мира, внутримировая версия или художественный текст, события которого ещё не приняты в канон.

Для хронологии обозначаем охватываемый период и принятую систему датировки, если они определены. Для внутримирового источника — автора или носителя версии, если он известен. Неизвестные даты и происхождение не заполняем догадками.

Старые версии авторских хронологий сохраняем с явной отметкой, что они заменены, и ссылкой на актуальную версию, если она есть. Не смешиваем устаревший материал с действующим каноном.

Утверждение рассказа как текста не делает все его события и утверждения каноническими автоматически: границы принятого указываем отдельно. Описания участвующих сущностей остаются в своих предметных разделах, здесь используем ссылки на них.

Общие правила: [Контекст проекта](../КОНТЕКСТ%20ПРОЕКТА.md).
