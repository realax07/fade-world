# Деревни

Тип: описание типа поселений.
Статус: сельский характер страны утверждён; описание типа — рабочий набросок.

Небольшие сельские поселения, жизнь которых предлагается строить вокруг хозяйств, земли и доступных местных промыслов. Конкретное соотношение пашни, леса, скота и сезонной работы зависит от области.

В таком масштабе повседневные связи, распределение труда и обязанностей могут определять жизнь сильнее, чем непосредственное присутствие столичной власти. Это ориентир для разработки, а не утверждение одинакового порядка во всех деревнях.

Открыты: численность, устройство общины, землевладение, повинности и отдельные населённые пункты. Наличие тайного обычая или сверхъестественного не обязательно для каждой деревни.
