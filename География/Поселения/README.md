# Поселения

Деревни и сёла составляют основную сеть обитаемых мест Вележа. Посёлки дополняют её там, где жизнь связана с производством, промыслом, дорогой или иной местной деятельностью.

Пока созданы описания типов, а не конкретные населённые пункты:

- [Деревни](./Деревни/README.md).
- [Сёла](./Сёла/README.md).
- [Посёлки](./Посёлки/README.md).

Сельский характер страны утверждён. Различия типов ниже — рабочие наброски для дальнейшего обсуждения; юридические и религиозные признаки не установлены. Конкретное место в дальнейшем получает собственную папку и ссылку на область. Названия и перечень таких мест пока открыты.

Общий контекст: [География](../README.md).
