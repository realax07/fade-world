# Сёла

Тип: описание типа поселений.
Статус: сельский характер страны утверждён; описание типа — рабочий набросок.

Более заметные сельские центры, которые могут связывать несколько соседних поселений через обмен, ремесло и общие нужды. Их значение определяется окружающей местностью и путями сообщения.

В качестве дальнейших вариантов можно рассматривать торг, мастерские, место собраний или религиозное учреждение. Эти признаки пока не объявлены обязательными и не задают устройство религии мира.

Открыты: отличие села от деревни в местном употреблении и праве, размеры, управление, функции и конкретные названия. Село остаётся частью преимущественно сельской страны, даже если играет роль местного центра.
