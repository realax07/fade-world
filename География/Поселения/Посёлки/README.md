# Посёлки

Тип: описание типа поселений.
Статус: рабочий набросок. Поселения при производстве и промыслах согласованы в общем географическом каркасе; конкретная типология открыта.

Поселения, развитие которых связано с определённой деятельностью: заводом, рудником, пристанью, лесным промыслом или обслуживанием пути. Состав жителей, хозяйство и снабжение могут зависеть от работы этого места.

Для последующей разработки важно определять, кто содержит поселение, как оно связано с окрестными деревнями и городами и что происходит при прекращении основной работы. Пока это вопросы описания, а не установленная история отдельного посёлка.

Открыты: собственные названия, принадлежность, постоянный или сезонный характер проживания, управление и конкретные занятия.
