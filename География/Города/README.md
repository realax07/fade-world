# Города

Столица получила имя Велиград и утверждённый общий образ. Остальные три крупных центра пока описаны по функции; их папки сохраняют рабочие обозначения. Планы, население и конкретные события не выводятся из роли города автоматически.

- [Велиград](./Велиград/README.md) — столица; [Низины](./Велиград/Низины/README.md) и [Шиворот](./Велиград/Шиворот/README.md) описаны внутри папки города.
- [Старый город власти](./Старый%20город%20власти/README.md).
- [Крупный порт](./Крупный%20порт/README.md).
- [Промышленный город](./Промышленный%20город/README.md).

Помимо них в стране есть меньшие города: уездные центры, крепости, пристани, торговые и ремесленные города. Их конкретный список пока не составлен. Функции могут сочетаться; наличие столицы не исключает в ней торговли или производства.

Основная масса населения живёт в [сельских поселениях](../Поселения/README.md). Общий контекст: [География](../README.md).
