# Старый город власти

Тип: описание места — городской центр.
Статус: роль утверждена; собственное имя, положение и подробности открыты.

## Роль и характер

Город родовых связей, древних учреждений, архивов и накопленного богатства. Здесь старое наследство имеет вес через собственность, память и устойчивые отношения между людьми.

Его значение сохраняется при нынешнем государе и не сводится к сопротивлению преобразованиям. Конкретные позиции родов и учреждений пока не установлены. Статус прежней столицы был предложен как возможность, но не выбран окончательно.

## Открытые вопросы

Название, расположение, происхождение влияния, отношения с нынешней столицей, важные учреждения и семьи. Не заданы конкретные события переноса власти.
