# Внутренние горные хребты

Тип: описание группы географических объектов.
Статус: общий каркас утверждён; число, названия и расположение хребтов открыты.

## Облик и роль

Горы разделяют области и речные бассейны. Перевалы определяют пути между землями по разные стороны хребтов. В предгорьях возникают рудники, заводы и рабочие поселения, связывающие добычу с перевозками и государственными заказами.

Часть гор может служить границами, другие хребты лежат глубоко внутри Империи. Этот выбор пока открыт. Горы не сведены к одной сплошной цепи и не получили заданного направления на карте.
