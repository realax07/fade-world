# Север

Тип: описание географической зоны.
Статус: общий каркас утверждён; собственные названия и границы открыты.

## Облик и роль

Хвойные леса, озёра, болота и длинные речные пути. Поселения тянутся вдоль воды; между ними лежат большие необжитые пространства. Лесные промыслы и добыча сырья связывают север с остальной страной.

Доступность определяется маршрутом и сезоном. Зимняя дорога может облегчить движение, а распутица — прервать связь. Общая принадлежность Империи не делает все поселения одинаково доступными для снабжения, управления и поездок.

## Открытые вопросы

Граница с центральными и полярными землями, реки, промыслы, конкретные поселения и особенности местного уклада. Их детали предстоит согласовать отдельно.
