# Морские побережья

Тип: описание группы прибрежных зон.
Статус: общий каркас утверждён; названия морей и береговая линия открыты.

## Облик и роль

На севере Вележ выходит к холодному морю. Есть второе, более доступное для судоходства море на западе или юго-западе; окончательное направление пока не выбрано. Это разные морские направления, а не единая однородная область.

Прибрежные поселения связывают страну с морской торговлей и промыслами. Доступ к более удобному морю важен для преобразований Северина. Конкретные сроки навигации, флот и состояние гаваней пока не определены.
